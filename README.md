# BargazLive

BargazLive is a project focused on hosting the Bargaz websites and developing tools and services for livestreaming and content creators.
The project serves as both the web infrastructure for the Bargaz software ecosystem and the foundation for future livestreaming-related applications.

## Project Scope

BargazLive includes two primary areas of development:

### Website Hosting

BargazLive hosts and manages the websites associated with Bargaz, including:

- **[bargaz.app](https://bargaz.app)** — The main Bargaz website, providing information about Bargaz and its projects.
- **[bot.bargaz.app](https://bot.bargaz.app)** — The BargazBot website, providing project information, documentation, and related resources.
- **[live.bargaz.app](https://live.bargaz.app)** — The BargazLive website, which will provide information and access to its services as development progresses.

### Livestreaming Tools

BargazLive will also serve as a platform for developing tools intended to support livestreamers and their communities.
Planned areas of development include a chatbot capable of supporting multiple livestreaming platforms, along with other tools and services that may be introduced as the project evolves.
Specific features, integrations, and supported platforms will be determined during development.

## Development Status

BargazLive is currently in early development.
The initial infrastructure includes:

- A Next.js web application.
- Website hosting through a Raspberry Pi using PM2.
- Public website access through Cloudflare Tunnel.
- GitHub integration for retrieving BargazBot repository content and documentation.

Livestreaming-related functionality has not yet been implemented.
